# Сервис событий:
- Пользователь отправляет id задачи и тип события
- По jwt токену бэкенд определяет id пользователя
- Событие сохраняется по id задачи и id пользователя
# Сервис статистик:
- Статистика может вычисляться по: пользователю, задаче, пользователю и задаче, по всему сервису
- На данный момент можно вычислить следующие статистики: успешность выполнения задач, сумма конкретного события
